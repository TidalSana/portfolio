KORSA MINI — STANDALONE STUDIO STUDY

Serve this folder over HTTP and open index.html. It is self-contained and has no
build step or remote runtime dependencies. Example from this folder:

  python3 -m http.server 8777

Drag the keyboard to orbit, scroll to zoom, or select the five preset views: Perspective, USB edge, Plate, Underside, and Side recess.
Save PNG downloads the current opaque canvas at your display's render resolution.

This is a visual reconstruction, not manufacturing CAD. Original Cherry community
CAD caps, estimated Korsa-inspired case, 60% WKL layout, 7u spacebar, rose gold
#d5b7b3 case, Striker #345B94 alphas with dark Escape/Enter. See SOURCES.md for
provenance and geometry limitations. No paid Keyboard Render Kit assets are used.

The portfolio source remains untouched. All runtime files are copied locally.
